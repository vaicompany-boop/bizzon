# Bizzon

Bizzon is a boring-but-useful utility tools website: simple browser-based tools that just work.

## MVP

- Astro + Tailwind
- Homepage
- Tools index
- Word Counter at `/word-counter`
- Static deployment target: Vercel

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Privacy baseline

The first tool, Word Counter, runs client-side in the browser. Pasted text is not uploaded to a server.
