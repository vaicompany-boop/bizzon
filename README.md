# Bizzon

Bizzon is a boring-but-useful utility tools website: simple browser-based tools that just work.

## MVP

- Astro + Tailwind
- Homepage
- Tools index
- Live text/SEO utility tools tracked in `src/data/tools.ts`
- Converter + social creator roadmap tracked in `BIZZON_CONVERTER_SOCIAL_ROADMAP.md`
- Static deployment target: Vercel

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Privacy baseline

The first tool, Word Counter, runs client-side in the browser. Pasted text is not uploaded to a server.
